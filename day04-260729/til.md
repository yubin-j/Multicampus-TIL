### API 키 관리에 대한 질문

키 값이 하드코딩 되는 것이 우려되어 페이지에서 api키를 입력받는 형태로 했고, .env 파일은 클로드가 열지 않는다는 제약도 넣었다.

그런데 테스트 시 키 값을 클로드가 알고 있었다. 물어보니 파일 변경사항이 생기면 파일 변경 감지 훅으로 읽을 수가 있다고 함.

알게된 것
 - 페이지에서 api키를 입력받는 것보다 FastAPI 서버가 로컬에서 자동으로 참조하는 형태가 가장 좋다
 - 클로드가 key를 모르게 하려면 아예 작업 폴더에서 분리하거나 지침에 넣는 방법이 있음
 - 가장 확실한 건 개발이 끝난 뒤 해당 key를 삭제하고 새 key를 발급받아 배포하는 것
