### https://google.com을 웹 브라우저에서 입력하고 엔터를 누르면 어떤일이 일어나는가

주소를 dns에 쿼리하여 ip 주소를 가져온다

ip 주소에 http request를 하여 데이터를 요청 한다.

ip주소를 가지고 있는 서버에서 응답을 처리하여 데이터를 반환한다.

브라우저는 받은 데이터를 해석하여 표시해준다.

-> 정리

웹 브라우저는 클라이언트로서 서버로 요청을 보내는 역할을 합니다.

https 프로토콜을 이용한 요청을 보내는데, google.com 이라는 도메인에 해당하는 ip를 갖고있는 전세계 어딘가에 있는 서버 컴퓨터로 요청을 보냅니다.

이때 이 요청이 웹 페이지를 보여달라는 요청이라면 응답으로 코드가 가득한 응답을 줍니다.

그러면 내 웹 브라우저는 해당 코드를 랜더링(이쁘게 보여줌)을 거쳐서 내게 보여주게 됩니다.

### 요청과 응답

요청 메서드 종류 - get, post

용도가 다름

프로토콜, 포트에 대한 내용 진행

응답의 상태코드 - 100, 200, 300, 400, 500
