## SSR / CSR

프론트 코드가 서버에서 브라우저로 이동해서 브라우저 자체에서 서버로 요청함

ssr은 검색엔진 조회 가능 -> 크롤링 가능 -> SEO

robots.txt -> 크롤링 시 규칙을 사이트에서 지정한 문서
 - User-agent: -> 접속 대상자
 - Disallow: -> 거부하는 경로
 - Allow: -> 허용하는 경로

크롤링 전문 회사 -> 특정 사이트로 요청을 해보고 안 뚤리면 실제 기기를 조작해서 접근

SPA와 부분 로딩의 구분
 - "페이지 이동 시에도 리로드 없이 필요한 부분만 갱신" -> 이건 SPA 맞음
 - "한 페이지 안에서 일부 콘텐츠만 비동기로 갱신" -> 이건 SPA든 아니든(심지어 순수 MPA에서도) 가능한, 더 넓은 개념의 "부분 로딩/AJAX"

ssr + csr => 서로의 장점을 모아서 운영 -> next.js
