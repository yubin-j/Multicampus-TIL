## 스코프

지역, 전역 스코프 설명

LEGB rule
 - L - local - 현재 함수 내부에서 사용
 - E - enclosing - 중첩 함수의 변수들
 - G - global - 전역
 - B - built-in - 내장 함수

L에서 B방향으로 접근이 가능하지만 영향을 미치진 못함

B에서 L방향으로는 접근 불가

내부 공간에 상위 공간에 있는 변수와 동일한 이름을 가지는 변수를 사용하는 상황에서 전역의 변수에 접근하고 싶으면 global 키워드를 변수 앞에 붙여줘야 사용가능

-> 근데 이런 패턴은 애초에 안 쓰는게 맞음..

if, for에 관한 블록은 없다.

참조형 변수 - 리스트의 원소는 스코프가 달라도 변경이 가능

### 트럼프 카드를 정렬하는 방법

아이디어 고민

2~10, J, Q, K, A / 클로버, 하트, 다이아, 스페이드

같은 숫자여도 문양에 순서대로 등급 선정됨

2~A까지 배열에 두고 이 배열의 인덱스를 가져와서 정렬

그런데 문양 정보도 있으니까 아래와 같은 식을 이용해 정렬

```
(i + 1) * 스페이드(4)
(i + 1) * 클로버(1)
```

입력으로 들어오는 것에 대응하게 하고자 하면 객체에 카드 숫자에 대응하는 가중치를 적용해두고 위와 동일 로직으로 수행

```python
card_value = { 1: 1, … , A: 14}
```

강사님 방식은 1~10까지만 고려하고 문자는 고려하지 않음

dictionary에 키 값으로 카드숫자값을 넣고 카운트를 올림

dictionary를 range(1,11)로 돌면서 카운트 만큼 카드숫자를 출력함.

-> 계수정렬

객체대신 숫자 범위가 10개밖에 안 되니 배열에 카운트를 넣는 방식으로 변형함

트럼프카드와 같이 범위가 정해져 있는 경우에는 이게 가장 빠르긴 함. O(N + 10)
